# Before / After Analysis

| Area | Typical first draft issue | Improved version in this kit |
|---|---|---|
| Summary | Generic statement such as “seeking a challenging job” | Identifies CSE student status, development interest and current skills |
| Skills | Long unverified list | Limited to stated skills and grouped by type |
| Experience | Internship title only | Adds duration, project context and learning; asks student to verify exact contribution |
| Projects | Project name without explanation | Uses problem / role / tools / result structure as an editable pattern |
| ATS readability | Decorative template and mixed headings | Plain text resume structure with standard headings |
| LinkedIn | Empty or very short profile | Headline, About section and five introductory posts |
| Accuracy | AI may add unsupported metrics | Placeholders and verification checklist prevent invented claims |

## Evaluation
The revised draft is clearer, more targeted and easier to scan. No ATS score or recruiter outcome is claimed. Final quality depends on completing placeholders with verified details and matching each application to its job description.
