# Resume and Profile Quality Checklist

## Resume content
- [ ] Name and contact details are correct.
- [ ] Education title, college and dates are verified.
- [ ] Skills are genuinely practised and explainable.
- [ ] Internship title, organisation, duration and dates are accurate.
- [ ] Project descriptions state personal contribution.
- [ ] No invented metrics, grades, certifications or achievements.
- [ ] Role keywords match the job description only when truthful.

## Resume readability
- [ ] One-page, simple layout where suitable.
- [ ] Standard headings and consistent dates.
- [ ] Clear font and sufficient white space.
- [ ] No unnecessary graphics, tables or text boxes.
- [ ] Spelling and grammar checked.
- [ ] PDF opens correctly and text can be selected/copied.

## LinkedIn
- [ ] Headline is clear and accurate.
- [ ] About section sounds authentic.
- [ ] Education and internship are verified.
- [ ] Skills and project links are current.
- [ ] Privacy and contact visibility reviewed.

## Portfolio
- [ ] All navigation links work.
- [ ] All project descriptions reflect actual work.
- [ ] No private data, passwords or personal address.
- [ ] Mobile layout tested.
- [ ] Placeholder links and email replaced before publishing.
